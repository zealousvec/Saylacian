This inventory applies to files and package references in the Saylacian source repository. It does not claim a single licence covers all repository contents. GNU AGPL-3.0-or-later applies only to Saylacian-authored code that the project licensor owns or has the right to license; marked data, fonts, charts, datasets, models, and third-party dependencies keep their own terms.

- **Borama and Kaddare chart images** (`assets/research/`) by Jugydmort, CC BY-SA 4.0. Chart-derived mappings (`saylacian/core/data/scripts/borama.json`, `kaddare.json`) and bitmap-derived PUA display fonts (`assets/BoramaChart-Regular.ttf`, `KaddareChart-Regular.ttf`) are adaptations and are separately marked CC BY-SA 4.0. These are partial experimental chart-label mappings, not standard Unicode or validated general orthography.

- **Noto legacy duplicate** `assets/original/Fonts/Noto Sans Osmanya.ttf` has the same SHA-256 as `assets/NotoSansOsmanya.ttf` and is retained because `app/original.kv` still names that historical relative path. ## Transitive Material Design Icons font

Saylacian source does **not** vendor the Material Design Icons TTF. It depends on `KivyMD==1.2.0`, pinned in `requirements-runtime-lock.txt`. The immutable [KivyMD 1.2.0 PyPI release metadata](https://pypi.org/project/KivyMD/1.2.0/) identifies the Iconic font as by the Material Design Icons community and declares SIL Open Font License 1.1. The installed wheel's font name table says “Version 1.0” and “Generated by svg2ttf from Fontello project”; KivyMD does not pin an upstream icon-font commit. For this source repository, the binary arrives only with the declared third-party dependency and its upstream notice resolves the dependency's stated licence. The PyInstaller recipe collects KivyMD assets, so any Windows binary distribution must include OFL attribution and verify its exact packaged font. The current MDI OFL text is retained at `notices/SIL-OFL-1.1-Material-Design-Icons.txt`.

## Python dependencies

`requirements-runtime-lock.txt` pins the Kivy app/runtime dependency set; `requirements-website.txt` contains optional Flask. CI/dev tools are in `requirements-dev.txt`. Dependencies are installed from their upstream package repositories and are not copied into this source tree. Their upstream package notices apply. Checked package metadata lists include MIT (Kivy, KivyMD, Kivy-Garden, CTranslate2, charset-normalizer, filetype, PyYAML); Apache-2.0 (`notices/Apache-2.0.txt`, shared by Requests, SentencePiece, and the pinned OPUS-MT pack); BSD-family / public-domain alternatives (NumPy, py3langid, Pygments, Docutils, idna); MPL-2.0 (certifi); HPND (Pillow); PSF (pywin32); MIT (kivy-deps.angle / glew); and zlib (kivy-deps.sdl2). Some transitive packages publish multiple licences or incomplete PyPI metadata; inspect the exact pinned distribution before redistributing a built binary. Kivy declares `pypiwin32` as a Windows-only transitive dependency. Its PyPI 223 distribution is a metadata-only wrapper with no importable files or licence file and reports `UNKNOWN`; the application separately pins `pywin32` (PSF). Neither package source nor DLLs are vendored here. Their presence must be rechecked in any binary bundle.

The source repository contains no Windows DLLs or installer binaries. Native DLL notices are therefore a separate Windows binary-release check, not a source-repository blocker. See `docs/PACKAGING.md` before building or distributing a binary.

## Root project code licence

The root `LICENSE` is the complete, unmodified GNU AGPL version 3 text. Saylacian-authored code that the project licensor owns or has the right to license is offered under AGPL-3.0-or-later. This approval does not extend to third-party code or independently licensed assets/data. Creative Commons lists GPLv3 (one-way) as compatible with CC BY-SA 4.0 adaptations; it does not list AGPL. Accordingly, chart-derived files remain under CC BY-SA 4.0 and are outside the AGPL code grant. Noto fonts retain SIL OFL 1.1; the TICO fixture preserves CC0 plus per-row source-material terms; downloaded model weights retain manifest-declared upstream licences; dependency components remain under their own upstream licences.
