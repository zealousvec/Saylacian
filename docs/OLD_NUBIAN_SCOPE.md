# Old Nubian reading scope

Saylacian provides limited character transliteration between selected Coptic-derived Old Nubian characters and scholarly Latin readings. It does not translate meaning, provide a complete alphabet, interpret manuscripts, or support modern Nubian varieties such as Nobiin, Kenzi/Mattokki, Dongolawi/Andaandi or Midob.

The current table has 34 character readings. Unknown characters are preserved with a warning; reverse Latin-to-script conversion can be ambiguous. Saylacian preserves combining marks. It also offers an `i`-based alternative for the combining macron used as a supralinear stroke, following one published convention; it does not claim this is the only reading or that mark placement has been validated across editions. Other marks are not interpreted. No fluent or specialist review has confirmed the full table or reading conventions.

The readings are based on the DBMNT transliteration table: [source PDF](https://dbmnt.uw.edu.pl/static/pdf/transliteration_tables.pdf) and [General Guidelines](https://dbmnt.uw.edu.pl/guidelines/general/). The public guidelines describe downloading but do not state a reuse licence or permission grant. Redistribution rights for this derived table remain unresolved. The app does not include manuscript passages or a word lexicon from the CC BY-NC-SA Old Nubian edition.
