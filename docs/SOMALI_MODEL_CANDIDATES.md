TICO-19 is a small domain-focused evaluation here; training overlap is not fully established, and automatic metrics do not determine whether a Somali sentence is faithful. Do not tune candidate parameters on the held-out test set. Human review by fluent Somali speakers is still required.

The Google-hosted Q4 GGUF variant was also downloaded from a pinned official repository revision and hash-verified, but the installed `llama-cpp-python 0.3.36` parser rejected it because a tensor name exceeded its 64-character limit. It was not loaded or benchmarked; the CTranslate2 candidate above was tested instead.

## AfriSLM prompt check

Compared the current app prompt with a concise prompt that explicitly requests Somali written in Latin script. The 0.8B Q4 model was run locally with network connections blocked, using 60 unique, deterministic TICO-19 English→Somali development pairs not present in earlier prompt experiments (30 screen, 30 separate confirmation; archive SHA-256 `0e82fc7ceaa877606c8934f32ead185716c9d2c54b3818f2a7ae655f5e7a08d8`; model SHA-256 `4af8ee1df3ec9008f763ebe95e6f21df3acd8d42c541feeb13314ca22e560afc`). On the screening slice, current/concise BLEU and chrF++ were `7.134/24.532` and `7.003/24.023`; concise mean CPU time was `1.778 s` versus `2.169 s`. On the confirmation slice, they were `2.581/22.526` and `3.366/23.392`; concise mean CPU time was `1.949 s` versus `1.851 s`. The quality measures disagree across the two slices and latency also moves in opposite directions. No prompt or route change is justified. These small, single-reference medical-domain metrics do not establish human adequacy. Raw results remain outside Git; no held-out test split was used.

## Sunflower-Qwen3.5-9B candidate

Sunbird publishes an Apache-2.0 preview checkpoint with reported Somali chrF `0.5578` EN→SO and `0.6994` SO→EN on its SALT69 test set. The official base repo is pinned at `c56081c5024b1c11186a69898f5f6a7a2dabe454` (18.82 GB BF16); its official bitsandbytes 4-bit derivative is 7.9 GB and pins the base to `10156eaa72a329ee5bef01a72d561fb1923274d2`. The 4-bit card requires Transformers/bitsandbytes and documents CUDA usage; its three quantized files total about 7.9 GB. This Windows environment has llama-cpp-python `0.3.36`, no PyTorch/Transformers, and an 8 GB GPU, so the published 4-bit checkpoint cannot be fairly evaluated with the app's current runtime or fit entirely on the GPU alongside inference memory. The model is a preview and its SALT69 result is not directly comparable with Saylacian's TICO/FLORES scores. Candidate for a compatible evaluation host only; no pack, dependency or route change. [Official model card and metrics](https://huggingface.co/Sunbird/Sunflower-Qwen3.5-9B); [official quantized card](https://huggingface.co/Sunbird/Sunflower-Qwen3.5-9B-bnb-4bit); [SALT model documentation](https://salt.sunbird.ai/models/sunflower-qwen3.5-9b/).

The related Sunflower-Gemma4-E2B preview reports Somali chrF `0.5180` EN→SO and `0.5647` SO→EN on SALT69. Its repository declares Apache-2.0 but is gated by a contact-sharing condition; its BF16 file is 10.2 GB, and no access request or weight download was made. No separately published Sunflower GGUF was found in the public model search. It is not a practical candidate for this host's current runtime/GPU, and access conditions must not be accepted on the owner's behalf. [Official model card and metrics](https://huggingface.co/Sunbird/Sunflower-Gemma4-E2B); [SALT model documentation](https://salt.sunbird.ai/models/sunflower-gemma4-e2b/).

## Somast `som-en-mt` preview

Somast's docs list `som-en-mt` as a Somali translation model and say its models are hosted in the `somast` Hugging Face organization. The current public organization API lists only `somast/somali-bpe-v2` (a tokenizer), with no translation checkpoint to pin, license to review, or local inference to run. Keep this candidate blocked until Somast publishes the model artifact, revision, card and reuse terms; do not substitute a hosted demo for Saylacian's local model route. [Somast model docs](https://www.somast.so/en/docs); [public Somast model organization](https://huggingface.co/somast).

Goobo Labs' `SomNLP-Translate` could become a future source for training data, but its public repository currently reports only its M1 foundation complete; OPUS/MT560 downloaders and leakage-resistant splits remain planned. No parallel corpus artifact was available to evaluate. [Repository and roadmap](https://github.com/goobolabs/SomNLP-Translate).

## 2026-10-25 — compact EN→SO candidate and output-safety guard

Screened `WindyTranslate/translate-synthetic-en-so` at pinned revision `82e552c1938e34656ca5c9a7ea6220cc91286c1b`, model SHA-256 `1a58fd35a39d206195b8ed2b0b31c4d87d8bc1487d46dbbd3d4f1a09fd8d4e12`, converted to CTranslate2 INT8 for a local-only comparison. On 60 deterministic, length-stratified TICO-19 development examples, the candidate scored BLEU/chrF++ `2.718/21.687` versus Saylacian's current route `4.215/21.919`; it was faster (`774 ms` vs `1,584 ms` mean CPU time) but quality metrics were lower. The sample is small, medical-domain, and single-reference. Reject for routing. Its card declares CC-BY-4.0 but does not identify its training corpus, so do not redistribute or integrate it without provenance review. Real candidate predictions also exposed `U+2047` unknown-token corruption and repeated output.

Applied Saylacian's existing conservative degeneration checks to optional AfriSLM output: copied input, repeated sentences, implausible expansion, or the known unknown-token marker now falls through to the standard offline route with a warning. A regression covers copied input and verifies the fallback result. This is a reliability guard, not a claim that model output is accurate. Focused translation suite: `33 passed`; full suite: `182 passed, 2 skipped, 208 subtests`. Ruff check and format, compileall, `pip check`, and `git diff --check` pass.

Detection evidence remains insufficient to tune confidence: long MASSIVE source-locale agreement did not justify lowering or raising the current threshold. Next: continue screening rights-clear Somali candidates and seek independently adjudicated Somali detection data. No UI changes, model pack download, or push.
