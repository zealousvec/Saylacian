# Somali model candidate assessment

Research snapshot: 24 October 2026. Scores below are automatic comparisons only, not human-reviewed quality. The current guarded route remains selected unless a candidate has both reproducible quality evidence and a viable distribution/runtime path.

TICO-19 is a small domain-focused evaluation here; training overlap is not fully established, and automatic metrics do not determine whether a Somali sentence is faithful. Do not tune candidate parameters on the held-out test set. Human review by fluent Somali speakers is still required.
