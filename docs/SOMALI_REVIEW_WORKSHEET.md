# Somali translation review worksheet

Purpose: collect opt-in human feedback on machine-generated Somali/English results. This worksheet does not imply that any translation has already been reviewed.

## Reviewer instructions

- Review each direction separately: English→Somali and Somali→English.
- Judge meaning, naturalness, spelling, punctuation, and dialect/variety fit independently.
- Mark uncertain items as uncertain. Add a correction only when confident; explain alternatives where useful.
- Do not include names, addresses, health, financial, legal, or other private text. Examples are processed locally by Saylacian, but this sheet should not contain personal data.
- Participation is optional. Leave reviewer name/contact blank unless you explicitly want attribution or follow-up. Share this sheet only with the project maintainers through a channel you choose; Saylacian does not upload it.
