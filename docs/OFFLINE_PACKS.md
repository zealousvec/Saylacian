# Offline translation packs

Pack downloads are optional and begin only after you choose **Download** in Saylacian. Each pack is downloaded over HTTPS, checked against its pinned file sizes and SHA-256 hashes, staged, then activated. Progress and cancellation are available in the app. No model weights are included in this source checkout.

| Pack | Languages | Download size | Model licence |
|---|---|---:|---|
| French / English | English ↔ French | about 166 MiB | MIT |
| Somali / English | English ↔ Somali Latin | about 300 MiB | Apache-2.0 |
| Optional Somali translation model | English → Somali | about 62 MiB | CC BY 4.0 |
| AfriSLM Somali / English | English ↔ Somali Latin | about 672 MiB | Apache-2.0 model; see training-data terms |
| AfriSLM 2B Somali / English | English ↔ Somali Latin | about 1.46 GiB | Apache-2.0 model; see training-data terms |
| Optional Somali detection model | Somali input detection | about 25 MiB | MIT model; GPL-3.0 training dataset |

Installed packs are stored in the user's application-data folder, outside the project checkout. Use **Offline language packs** to see installed packs, install updates, cancel downloads or remove a pack to reclaim storage. Updating creates a versioned install; old versions remain until removed, so an update can temporarily need extra disk space.

The Somali detection pack is optional. After download, it can recover Somali input that the existing detector leaves uncertain. It does not translate text, and the existing English/French results take precedence. Detection runs on device; its model and runtime dependencies are pinned and work offline after installation.

The optional English-to-Somali pack uses a separate CTranslate2 model. Install the standard Somali/English pack first: Saylacian will not install the add-on without it, and will not remove the standard pack while the add-on is installed. The app tries the add-on first for English-to-Somali and falls back to the standard pack when its output appears copied, unreadable, repetitive or unfinished. This model has no published score in its model card and still needs fluent-speaker review.

AfriSLM is a separate, larger local model for both English↔Somali directions. Install the CPU runtime in the same Python environment as Saylacian with `python -m pip install -r requirements-afrislm.txt`. It uses `llama-cpp-python` and runs on CPU; first use can take longer while the model loads. If the runtime is missing or rejects a result, Saylacian uses another installed Somali model. Incomplete internal-thinking output is rejected and falls back instead of being shown as translation. The 0.8B pack is about 672 MiB. The optional 2B pack is about 1.46 GiB; Saylacian selects it only when the device has more than four logical CPU cores and at least 4 GiB of available physical memory. Otherwise it uses the 0.8B pack if installed, or the standard Somali pack. A guarded model result can also fall back to the standard pack. The model cards list the weights as Apache-2.0, and separately identify CC BY-NC-4.0 synthetic training data and the NLLB-200 teacher model. These are separate upstream terms; see [AfriSLM 0.8B](https://huggingface.co/qvac/TranslatePsy-AfriSLM-0.8B) and [AfriSLM 2B](https://huggingface.co/qvac/TranslatePsy-AfriSLM-2B-Q4-GGUF). [llama-cpp-python CPU install](https://github.com/abetlen/llama-cpp-python).

On devices with four or fewer logical processors, Saylacian limits translation and optional language-detection inference to one CPU thread, uses a smaller beam for the standard translation route, and skips AfriSLM automatically in favour of the standard Somali model. The 2B pack additionally needs at least 4 GiB of currently available physical memory. On other devices, AfriSLM can still be slow because it is a large model.

In Saylacian's first 120-pair FLORES-200 sample, the optional route with fallback scored BLEU 10.755 / chrF++ 40.069; the standard pack scored 5.353 / 29.882. A second sample exposed 11 candidate results that ended with an unprompted ellipsis, so the app now falls back for those likely incomplete translations. With that guard, the second sample scored 10.470 / 37.983 versus 4.432 / 29.789 for the standard pack, with 31 fallbacks among 120 inputs. These are small automatic comparisons, not proof of fluent or meaning-preserving Somali. See the [full method and limitations](TRANSLATION_QUALITY.md#optional-english-to-somali-model-on-flores-200).

The optional detector is a fallback for uncertain short text; confident English or French results still take precedence. Its Somali threshold is 0.98. In a fresh run on 67 short, verified Qor texts, the base detector labeled 37 and the integrated detector labeled 40. A separate earlier check found no Somali predictions in 11,386 short MASSIVE texts from 52 non-Somali locales at 0.98; lowering the threshold to 0.90 recovered more Qor texts but produced one Somali prediction in that sample. Keep 0.98 for now. Dataset labels are proxies, not specialist-verified judgments; these samples do not establish general accuracy. See [the threshold evaluation](TRANSLATION_QUALITY.md#optional-detector-threshold-calibration).

The matched 120-row HornMT comparison found a modest metric gain for 2B over 0.8B in both directions, with about twice the mean warm latency and an observed working set of about 2.3 GB. This is one news-domain sample, not a fluency assessment or proof that training data are independent from the benchmark. See the [full comparison](TRANSLATION_QUALITY.md#optional-afrislm-2b-comparison).

### Short-text detection check

The detector now accepts inputs with at least eight characters and three words before classifying them; previously it required 12 characters. On the pinned Qor Af-Soomaali v0.4.0 release (revision `5234876e5019cc4b1c79096c9f046fe2f8113b1e`, SHA-256 `f53ec99fbbd620ac65412d0c26c62a80faa534b9a939e95a0da6c53d5b38c60c`), after the project's verified free-writing, length, and duplicate filters, the base detector recognized 2,456 of 3,477 first-three-word snippets at the old threshold and 2,493 at eight characters. Three snippets were labeled English at both settings. The optional OpenLID pack was not installed.

On 1,012 three-word prefixes per language from the hash-verified FLORES-200 devtest archive, correct labels rose from 205 to 233 English, 359 to 374 French, and 789 to 802 Somali; no wrong supported labels appeared at either threshold. Full-sentence results were unchanged (1,003/1,012 English, 1,010/1,012 French, 1,012/1,012 Somali), as were the earlier six-word prefix/suffix mixed probes. The separate three-word mixed-fragment results are summarized below. This is a measured improvement on two fixed datasets, not a guarantee for arbitrary short or code-switched text. Qor and FLORES text stayed in Temp; only aggregate counts are recorded here. Qor source: [Qor Af-Soomaali, v0.4.0](https://huggingface.co/datasets/unkadlabs/qor-af-soomaali), Unkad Labs and the Qor Af-Soomaali contributors, CC BY-SA 4.0. FLORES source and license: [FLORES-200](https://github.com/facebookresearch/flores/tree/main/flores200), CC BY-SA 4.0.

With the eight-character floor fixed, the short-text confidence threshold was also compared at 0.75 and 0.70. At 0.70, Qor Somali labels on three-word snippets rose from 2,493 to 2,568, while English labels rose from 3 to 6. Four-word Qor snippets gained 12 Somali labels with no increase in English labels; five-word results were unchanged. FLORES three-word correct detections rose by 29 English, 33 French and 23 Somali, with no added wrong labels in those controls. A separate synthetic check combined two English words with one Somali word, or one English word with two Somali words, in both orders. At 0.70, 981/4,048 probes received a single-language label, compared with 909/4,048 at 0.75; neither setting reliably detected these short mixtures. Six-word prefix/suffix probes were unchanged. Saylacian keeps 0.70 for the measured short-text coverage gain, with the increased mixed-input guesses documented as a limitation. These fixed samples do not guarantee general accuracy. The evaluation uses only aggregate outputs; Qor and FLORES text remains outside the repository.

A full 1,012-pair-per-language FLORES-200 devtest check found the optional detector left full-sentence results unchanged. On three-word Somali prefixes, correct detections rose from 789 to 810 of 1,012; no new Somali labels appeared for the 1,012 English or 1,012 French sentences in this sample. I also tested extending the optional model's window from five to six words. Six-word Somali prefixes gained only three detections (995 to 998), while Somali labels on constructed mixed English–Somali probes rose from 367 to 454. The app keeps the five-word cutoff to avoid that observed increase in mixed-text guesses. The check used the pinned OpenLID revision and the locked detector runtime: py3langid 0.4.0, ONNX Runtime 1.31.0 and Tokenizers 0.23.3. This is a limited corpus test, not a general accuracy guarantee; raw sentences were not retained.

Translation packs work locally without a network connection, account, per-request fee or artificial daily quota. Somali output has not had fluent-speaker review, so check important translations before relying on them. See the [support matrix](SUPPORT_MATRIX.md).

The exact upstream repositories, revisions, hashes, sizes and licences are in the files under `saylacian/core/data/`, including the AfriSLM 0.8B and 2B manifests. Model terms are separate from the Saylacian code licence; see [third-party notices](../THIRD_PARTY_NOTICES.md).
