Support and privacy

English ↔ French and English ↔ Somali meaning models run locally. Somali translation is in alpha testing and needs fluent-speaker review. Somali ↔ French uses English as an intermediate step, so errors can compound. Somali Latin / Osmanya changes the writing system, not meaning. This website does not offer Borama or Kaddare. Old Nubian support is a limited 29-character transliteration table from Coptic-derived writing to scholarly Latin; reverse conversion can have ambiguous letter boundaries. Neither route translates Old Nubian meaning or covers every convention. Modern Nubian varieties are not supported.

The server processes text only when you choose Convert and does not save translation history on this development site. Public hosting is not set up.
