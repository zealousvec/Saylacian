# Security policy

Saylacian is a Windows desktop app in alpha testing. Do not send credentials, private translation content, or vulnerability details through public issues.

GitHub private vulnerability reporting is enabled for this repository (checked
2026-11-07). Use [Report a vulnerability](https://github.com/zealousvec/Saylacian/security/advisories/new)
to submit a private report. Do not disclose vulnerability details in a public
issue. If the private form is unavailable, do not post sensitive details publicly.

Maintainer notification delivery has not been independently verified. Enabling
the reporting form does not establish a monitored inbox or a response-time
guarantee. Account notification and repository security settings are managed by
the repository owner.

The project does not promise a response time or security support for old versions. Please include the affected version, platform, and a minimal reproduction in a private report, and omit personal translation data.
